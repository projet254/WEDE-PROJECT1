## 3. Project Overview

Brew-Haven is a responsive website for a local coffee shop in Mankweng, Limpopo, South Africa. The website aims to introduce the coffee shop to potential customers and provide important information in one place. Its target audience is students and coffee lovers aged approximately 18–45.

The website uses HTML5 and CSS3. JavaScript enhancements are planned for Part 2, while further improvements, testing, and deployment are planned for Part 3.

## 4. Website Goals and Objectives

The goals and objectives of the website are to:

1. Increase Brew-Haven's online brand visibility.
2. Display the coffee shop's menu, prices, and opening hours.
3. Make it easier for customers to contact the business through a contact form and map.
4. Provide a responsive experience on desktop, tablet, and mobile devices.
5. Create a clean, user-friendly design that supports fast loading.

## 5. Key Features and Functionality

The website has five main pages:

- **Home (`index.html`):** Introduces Brew-Haven and provides a main call to action.
- **About (`about.html`):** Provides information about the coffee shop.
- **Menu (`menu.html`):** Displays menu items and prices in categories.
- **Gallery (`gallery.html`):** Presents images related to the coffee shop.
- **Contact (`contact.html`):** Provides contact details, a contact form, and a Google Maps location.

Other features include a responsive navigation bar, a hero section, a footer with opening hours and social links, semantic HTML elements, and responsive styling using CSS Flexbox.

JavaScript features planned for Part 2 include contact-form validation, a gallery slider, and a mobile navigation toggle. These should be marked as planned until they have been implemented and tested.
